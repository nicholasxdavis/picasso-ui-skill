# Picasso UI Skill

Design, inspire, implement, and critique interfaces with art foundations plus a human reference library. Hierarchy, Gestalt, composition, rhythm, color, motion craft, and a hard ban on AI-slop tells[cite: 1].

## Overview

This skill focuses on tasteful product UI and marketing surfaces. It absorbs former reusable-ui plates and an optional taste-skill gallery loop. It is not a Lighthouse gate and not an identity-asset factory[cite: 1].

## Installation

Add this skill folder to your agent configuration directory or reference it directly in your workspace instructions. Always apply `RULES.md`.

## When to Use

* Building or redesigning landing pages, dashboards, settings, or components
* Pages that feel generic, templated, or AI-made
* Needing human inspiration plates or adaptable interaction blocks
* Pre-ship visual critique and motion polish
